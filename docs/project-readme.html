A React Native mobile application for health insurance management.

About This Project

A health insurance management app providing policy lookup, activity management, and related features.

Requirements

  • Node.js >= 22.11.0
  • Xcode (iOS development)
  • Cocoapods
  • Android Studio (optional, for Android development)

Quick Start

1. Clone the project

git clone <your-github-repo-url>
cd HKEdgeApp

2. Install dependencies

npm install

3. Local configuration (important!)

iOS configuration

⚠️ Configuration files that require local changes:

  1. ios/.xcode.env.local (must be created on your machine)

Create the file and fill in your Node.js path:
export NODE_BINARY=<YOUR_NODE_PATH>

How to find your Node.js path:
bash which node

Example output:
/opt/homebrew/bin/node

  1. Install Pods dependencies
    bash cd ios pod install cd ..

4. Run the app

iOS simulator

Start the Metro server:

npm start

In a new terminal, run iOS:

npm run ios
# or specify a simulator
npx react-native run-ios --simulator="iPhone 15"

Android emulator

npm run android

FAQ

1. iOS build failure - wrong Node.js path

Error message:

/Users/.../Script-...sh: line 9: /opt/homebrew/Cellar/node/.../bin/node: No such file or directory

Solution:
Create the ios/.xcode.env.local file with the correct Node.js path:

# Find your Node.js path
which node
# Example output: /opt/homebrew/bin/node

# Create the configuration file
echo "export NODE_BINARY=/opt/homebrew/bin/node" > ios/.xcode.env.local

2. iOS build failure - xcscheme not found

Error message:

error Could not load the shared scheme for HKEdgeApp

Solution:
Make sure the file ios/HKEdgeApp.xcodeproj/xcshareddata/xcschemes/HKEdgeApp.xcscheme exists. If it is missing, use the default file included in the project.

3. pod install fails

Solution:

cd ios
pod deintegrate
pod install --repo-update

4. Metro cache issues

Solution:

npm start -- --reset-cache

常见问题

1. iOS 构建失败 - Node.js 路径错误

错误信息：

/Users/.../Script-...sh: line 9: /opt/homebrew/Cellar/node/.../bin/node: No such file or directory

解决方法：
创建 ios/.xcode.env.local 文件，填入正确的 Node.js 路径：

# 查找你的 Node.js 路径
which node
# 输出示例: /opt/homebrew/bin/node

# 创建配置文件
echo "export NODE_BINARY=/opt/homebrew/bin/node" > ios/.xcode.env.local

2. iOS 构建失败 - 找不到 xcscheme

错误信息：

error Could not load the shared scheme for HKEdgeApp

解决方法：
确保 ios/HKEdgeApp.xcodeproj/xcshareddata/xcschemes/HKEdgeApp.xcscheme 文件存在。如果缺失，使用项目中的默认文件。

3. Pod install 失败

解决方法：

cd ios
pod deintegrate
pod install --repo-update

4. Metro 缓存问题

解决方法：

npm start -- --reset-cache
