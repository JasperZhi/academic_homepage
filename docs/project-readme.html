一个基于 React Native 的健康险管理移动应用。

项目说明

这是一个健康险管理应用，提供保单查询、活动管理等功能。

环境要求

  • Node.js >= 22.11.0
  • Xcode (iOS 开发)
  • Cocoapods
  • Android Studio (可选，用于 Android 开发)

快速开始

1. 克隆项目

git clone <your-github-repo-url>
cd HKEdgeApp

2. 安装依赖

npm install

3. 本地配置（重要！）

iOS 配置

⚠️ 需要本地修改的配置文件：

  1. ios/.xcode.env.local（需要根据你的系统创建）

创建该文件并填入你的 Node.js 路径：
export NODE_BINARY=<YOUR_NODE_PATH>

如何查找你的 Node.js 路径：
bash which node

示例输出：
/opt/homebrew/bin/node

  1. 安装 Pods 依赖
    bash cd ios pod install cd ..

4. 运行应用

iOS 模拟器

启动 Metro 服务：

npm start

在新终端中运行 iOS：

npm run ios
# 或者指定模拟器
npx react-native run-ios --simulator="iPhone 15"

Android 模拟器

npm run android

常见问题

1. iOS 构建失败 - Node.js 路径错误

错误信息：

/Users/.../Script-...sh: line 9: /opt/homebrew/Cellar/node/.../bin/node: No such file or directory

解决方法：
创建 ios/.xcode.env.local 文件，填入正确的 Node.js 路径：

# 查找你的 Node.js 路径
which node
# 输出示例: /opt/homebrew/bin/node

# 创建配置文件
echo "export NODE_BINARY=/opt/homebrew/bin/node" > ios/.xcode.env.local

2. iOS 构建失败 - 找不到 xcscheme

错误信息：

error Could not load the shared scheme for HKEdgeApp

解决方法：
确保 ios/HKEdgeApp.xcodeproj/xcshareddata/xcschemes/HKEdgeApp.xcscheme 文件存在。如果缺失，使用项目中的默认文件。

3. Pod install 失败

解决方法：

cd ios
pod deintegrate
pod install --repo-update

4. Metro 缓存问题

解决方法：

npm start -- --reset-cache
