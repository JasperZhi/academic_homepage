Mapping of 7 Frontend Functions → Backend Endpoints

Frontend (api/*.js)                Backend (server.js)               Status
───────────────────────────────────────────────────────────────────────────────

① fetchPoliciesByCompany()  ────▶ GET /api/app/policies             ✅ Works
     Params: hkid, company             └ Returns policy list
     Purpose: load policies after selecting an insurer

② fetchHospitalsByPolicy()  ────▶ GET /api/app/policies/:id/hospitals  ✅ Works
     Params: policyNo                  └ Returns Completed contracted hospitals
     Purpose: see which hospitals a policy covers

③ issueQrToken()            ────▶ POST /api/app/qr/issue            ✅ Works
     Params: policy_id                └ Returns 60s token
     Purpose: generate dynamic QR code

④ refreshQrToken()          ────▶ Same as above (calls issueQrToken) ✅ Works
     Purpose: get a new token when the 60s one expires

⑤ syncFromConsole()         ────▶ GET /api/app/sync                 ✅ Works
     Params: hkid                       └ Returns policies + hospital stats
     Purpose: polling sync while the APP is in the foreground

⑥ fetchClaims()             ────▶ GET /api/app/claims               ✅ Works
     Params: hkid                       └ Returns claim records
     Purpose: view reimbursement history


⑦ verifyQrCode()            ────▶ POST /api/qr/verify               ❌ Broken!
     Params: qrData, hospitalId   The backend has no such route!
     Purpose: hospital scans QR    Only admin/qrcode/checkin exists


⑧ verifyPolicy()            ────▶ (no HTTP request)                 ❌ Fake!
     Purpose: patient KYC registration    Pure frontend mock, setTimeout + fake patient_id


⑨ sendChatMessage()         ────▶ POST /api/chat                    ⚠️ Half-working
     Params: sessionId, query          └ Forwards to n8n :5678        500 if n8n is not running
     Purpose: AI consultation

① fetchPoliciesByCompany()  ────▶ GET /api/app/policies             ✅ 通
     参数: hkid, company               └ 返回保单列表
     用途: 选保司后拉保单

     参数: policyNo                    └ 返回 Completed 合约医院
     用途: 看某保单覆盖哪些医院

     参数: policy_id                  └ 返回 60s token
     用途: 生成动态 QR 码

④ refreshQrToken()          ────▶ 同上 (调 issueQrToken)            ✅ 通
     用途: 60s 到期换新 token

⑤ syncFromConsole()         ────▶ GET /api/app/sync                 ✅ 通
     参数: hkid                       └ 返回保单 + 医院统计
     用途: APP 前台轮询同步

     参数: hkid                       └ 返回理赔记录
     用途: 查看历史报销

     参数: qrData, hospitalId   后端没有这个路由！
     用途: 医院扫码验证         仅 admin/qrcode/checkin 可用


⑧ verifyPolicy()            ────▶ (无 HTTP 请求)                    ❌ 假！
     用途: 患者 KYC 注册     纯前端 mock，setTimeout + 假 patient_id

     参数: sessionId, query          └ 转发到 n8n :5678             n8n 没启动就 500
     用途: AI 咨询
